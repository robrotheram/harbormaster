## Use the dashboard

1. [Open a project and find your way around](user-guide.md). Start here if someone has given you an account.
2. [Run your first agent task](work-conversations.md). Send a small request, inspect the output, and approve it.
3. [Review files and previews](reviews.md) or [analyze a dataset](data-science-workbench.md).

## Design a deployment

Read [system context and service topology](architecture/_index.md) to see how the parts fit together. Then use [deployment topology](architecture/deployment-model.md), [security boundaries](architecture/security.md), and [request flows](architecture/request-flows.md) to review isolation, data ownership, and failure behaviour.

## Develop Harbormaster

Begin with the [development guide](development/_index.md) for local setup, code ownership, and checks. Use the [code map](development/code-map.md) to find the package to change and the [service contracts](architecture/contracts.md) for API behaviour.

## Install and operate

Use the [deployment guide](deployment.md) to choose a runtime and install it. The [operations guide](operations/_index.md) covers configuration, validation, and recovery after installation.
